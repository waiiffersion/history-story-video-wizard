# Evidence and claim discipline

## Start with claims, not a bibliography

Split the planned story into testable claims. One row should express one claim, its role in the story, the source that supports it, the source's identity, and the wording allowed by the evidence.

Do not label an entire person, dynasty, or episode `E1` or `E2`. Evidence strength belongs to a specific claim.

## Source identity

Use four practical source families without treating age as a truth score:

| Family | Typical material | Safe use |
|---|---|---|
| Near-contemporary | inscriptions, excavated objects, administrative records | establish what the artifact directly shows; avoid reading missing context into it |
| Early transmitted account | received chronicles, speeches, biographies, canonical texts | report the tradition with source attribution when identity matters |
| Later or conflicting tradition | later compilations, variant manuscripts, retrospective anecdotes | show version differences; do not use alone to reconstruct a certain scene |
| Adaptation and modern memory | novels, opera, film, folklore, internet retellings | explain what audiences remember; never present it as the historical event |

For every source, record:

- identity and approximate date;
- distance from the described event;
- independence from other sources;
- purpose, genre, and likely audience;
- exact passage or object feature supporting the claim;
- corroboration and contradiction;
- what the source cannot establish.

## Claim certainty

Use the strongest wording the evidence actually allows:

- **Documented observation:** “The inscription names…” / “The object shows…”
- **Source claim:** “The transmitted account says…”
- **Supported inference:** “Taken together, this suggests…”
- **Contested interpretation:** “One tradition presents it as…, while another…”
- **Creative reconstruction:** keep out of factual narration, or label it explicitly as an illustration.

Absence of a record is not proof that an event did not happen. A vivid later story is not proof that it did.

## Action-chain gate

Before narrating `A caused B`, verify separately:

1. A is supported.
2. B is supported.
3. chronology permits the link.
4. a source or defensible inference supports the causal link.
5. plausible alternatives are not silently erased.

If step 4 fails, change “because” to a bounded formulation or remove the causal claim.

## Version-conflict rule

When versions conflict:

1. identify the smallest shared outcome;
2. describe each version's distinctive explanation;
3. keep the conflict visible if it changes the story's meaning;
4. never splice incompatible details into one seamless scene;
5. do not crown a favorite version merely because it is more cinematic.

## Spoken-script rule

Keep citations and apparatus in the evidence table and audit. Put a source name in narration only when at least one is true:

- the source conflict is the episode's central drama;
- the original phrase is a high-recognition anchor;
- knowing who recorded it changes the audience's interpretation.

Otherwise, tell the supported event naturally and keep the traceability backstage.
